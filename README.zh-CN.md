## ✨ 代表项目

| 项目 | 简介 |
| --- | --- |
| [**dsh-vision-router**](https://github.com/ysr666/dsh-vision-router) | 给纯文本 **DeepSeek Harness** Agent 装上“眼睛”：按需视觉路由，并提供定位、OCR、裁剪、像素差分、截图等视觉工具与内置免费视觉链路 |
